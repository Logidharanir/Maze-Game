🧩 Maze Game
A fun and interactive Maze Game built using HTML, CSS, and JavaScript. The player controls a cat sprite and must navigate through a dynamically generated maze to reach the home image. Difficulty levels are available to challenge players further!

🚀 Features
🌀 Dynamic Maze Generation with four difficulty levels: Easy, Medium, Hard, Extreme

🕹️ Arrow Key and Touch Swipe Controls

👦 Player Sprite: Moves through the maze

🏠 Goal Sprite (Home): End point to reach

🎉 Victory Message with move count

🌐 Fully Responsive and Mobile-Friendly

🛠️ Technologies Used
HTML5

CSS3

JavaScript (Vanilla)

jQuery

jQuery TouchSwipe

🕹️ How to Play
Open index.html in your browser.

Choose a difficulty from the dropdown.

Click Start to generate the maze.

Use arrow keys (or swipe on mobile) to move the player.

Reach the goal (home image) to win!
